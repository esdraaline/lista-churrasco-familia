# Lista do Churrasco

Checklist mobile para organizar o churrasco da familia.

Site publicado no GitHub Pages:

https://esdraaline.github.io/lista-churrasco-familia/

## Funcionalidades

- Lista pronta com carnes, bebidas, salada e sobremesa.
- Tomate ja consta na lista.
- Campo para adicionar novos produtos.
- Marcacoes e itens adicionados ficam salvos no aparelho.
- Botao para compartilhar a lista.
- Imagem de previa configurada para WhatsApp e redes sociais.

## Publicacao

O GitHub Pages usa a pasta `docs/` da branch `main`.

Para testar localmente a versao do Pages:

```bash
python -m http.server 4173 -d docs
```

Depois abra `http://localhost:4173/`.
